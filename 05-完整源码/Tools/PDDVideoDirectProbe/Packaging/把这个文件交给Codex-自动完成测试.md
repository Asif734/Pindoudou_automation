# 拼多多视频直链测试器自动测试说明

请协助这台电脑的使用者运行同目录中的“拼多多视频直链测试器.app”。

1. 确认拼多多商家版正在运行并已进入一个含有尚未播放视频的测试会话。
2. 启动测试器并点击“开始自动测试”。
3. 测试器会通过 AX 自动定位并点击当前聊天中最新的客户视频，无需使用者手动点视频。
4. 等待测试结束，读取桌面最新的“拼多多视频直链测试结果-*.zip”。
5. 只根据其中的 `result.json` 和 `测试报告.md` 汇报 PASS/FAIL、HTTP 状态、发现与下载耗时、时长、分辨率、编码及大小。

不要输出、复制或保存视频真实地址、拼多多缓存原文、Cookie 或登录信息。不要发送任何客服消息。
