# 拼多多视频直链测试器

这是一个与正式客服程序隔离的诊断工具。它用 AX 自动定位并点击当前聊天中最新、可见、客户侧的视频消息，同时监听所有拼多多 CEF 账号目录中新增或变化的 `_0`、`_s` 缓存元数据，提取新视频地址、下载原始 MP4 并生成脱敏报告。

- 不使用 OCR 或录屏。
- 会自动点击一条客户视频，但不发送消息、不操作订单、不启动客服程序。
- 不将视频地址、缓存原文或登录信息写入结果。
- 成功和失败都会在桌面生成结果文件夹和 ZIP。
- 超时会区分“CEF 缓存完全没有变化”和“缓存变化了但没有出现视频标记”。

测试时先打开含客户视频的拼多多聊天窗口，再点击测试器的“开始自动测试”。测试器会自动完成 AX 定位、点击、链接捕获、下载和验证。
