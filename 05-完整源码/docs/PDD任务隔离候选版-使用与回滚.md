# PDD 任务隔离候选版：使用与回滚

## 启动

1. 打开 `outputs/拼多多全自动客服-任务隔离候选版.app`。
2. 在 macOS 辅助功能和屏幕录制中允许该候选版；授权后重新打开。
3. 确认现有 `拼多多全自动客服` 没有运行。共享锁发生冲突时，候选版只显示提示，不会结束另一个进程。
4. 首次验证先勾选“干运行（不发送）”，再按“开始”。
5. 确认 OCR 文字、AX 图片、UID、队列和 Codex 生成正常后，再停止并取消干运行。

候选版每次启动都默认停止，不会因窗口出现而自动控制拼多多。

## 状态含义

- “第一次失败后已排到队尾”：当前 revision 会再试一次，其他用户先运行。
- “revision 已停放”：当前 revision 连续两次 UI 失败；不会阻塞其他用户，新 revision 仍能运行。
- “已完成 · 发送结果不确定”：发送驱动已经被调用，系统为防止重复发送而推进游标，不会自动重发。
- “最近警告（会继续运行）”：全局调度没有停止。

## 图片证据

原图存于候选数据根的 `images/<UID>/<客户游标摘要>/`。文件名包含消息 ID 和内容 SHA-256 前缀；任务 JSON 记录来源 URL、MIME、字节数和完整 SHA-256。

图片类型由 AX `image-msg` 判断，文字正文继续由 OCR 负责。图片下载失败时：文字+图片任务仍可使用文字继续；纯图片 revision 会按任务失败策略重排/停放，不会假装模型看到了图片。

## 停止与回滚

按“停止”会立即撤销当前 UI Lease；迟到的 AXPress、输入框写入或发送动作会被拒绝。关闭浮动进度窗不会停止工作，必须按主窗口“停止”。

回滚时先停止并退出候选版，再重新打开原 `outputs/拼多多全自动客服.app`。候选数据不会写入原版目录。若需恢复上一份候选 App，从 `outputs/backups/<时间戳>/` 复制回来，不要覆盖原版自动客服。

## 当前范围

候选版支持客户文字和客户原图输入 Codex。此阶段不包含知识库图片发送、文件发送或图片自动回复附件。
