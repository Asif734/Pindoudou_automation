# 拼多多客服工具

本项目生成四个相互独立的 macOS 应用：

- `outputs/拼多多AX读取器.app`：手动读取完整 AX 树、聊天解析和 Codex 建议。
- `outputs/拼多多AX单次解析测试器.app`：按一次执行一次 AX 读取和解析，用于观察 AX 更新延迟。
- `outputs/拼多多全自动客服.app`：现有自动客服版本。
- `outputs/拼多多全自动客服-任务隔离候选版.app`：独立数据目录、任务隔离、图片原图输入和持久化发送意图候选版。

## 候选版行为

候选版启动后默认停止，必须人工按“开始”。它使用截图像素识别未读红点、OCR 读取文字气泡、AX 定位会话和控件；AX `image-msg` 是图片类型的权威证据。

每个客户消息 revision 独立执行。拼多多 UI 操作由单一、可撤销 Lease 串行保护，并受外层超时控制：第一次 UI 失败排到队尾，第二次只停放当前 revision，其他用户和同一用户的新 revision 继续运行。

当前调度语义已经与现行千牛版对齐：已生成回复优先发送；采集失败只隔离本次任务，红点持续存在时允许重新发现；调度器不再重复执行发送前预检，最终 UID 校验由发送器负责；图片操作一经尝试就持久化，重试不会再次打开同一张图片；采集与补充采集的总超时均为 75 秒。状态文件在每一次 UI 操作前都会重新校验，只有状态文件被删除、替换或损坏时才停止全局调度，普通页面错误不会让其他客户失去回复。

发送前依次持久化 `.sending`、operation ID、`sendWasInvoked=false`，再持久化 `sendWasInvoked=true`，最后调用一次真实发送。重启时，调用发送前的中断会安全重新排队；调用发送后的中断会记为“已完成、发送结果不确定”，推进操作游标且不会自动重发。

Codex 自动客服输出只允许 `reply` 与 `reply_then_transfer`。两种动作都先生成并发送非空文字；乱码或意义不明时使用 `reply`，固定自然回复“亲亲，我这边没太听懂呢～”，不要求客户重复描述。只有客户明确找人工、明确办理退货退款、需要退款后台操作、远程协助、查询具体订单物流，或知识库排障已全部完成仍失败时，才允许 `reply_then_transfer`。

当前 `reply_then_transfer` 在回复生成完成时就同时持久化两个相互独立的任务：客套回复任务，以及绑定 UID、来源任务、客户 revision 和转人工原因的 `placeholder_pending` 转人工任务。客套回复只尝试一次；无论结果是成功、发送前失败还是发送结果不确定，转人工任务都不会被取消、推迟或丢失。同一 UID 的这两种任务合法共存，不会触发活跃回复任务冲突。当前转人工任务不点击拼多多界面；真实转人工动作等待后续单独接入。

## 客户图片

候选版通过 AX 消息 ID 和全局 frame 定位客户侧 `image-msg`，双击打开“图片预览”。它优先从预览 AX 树读取 HTTP(S) `AXURL`；如果拼多多没有暴露原图 URL，则使用预览窗口下方工具栏的“下载”区域。出现 macOS 保存面板后，程序通过 AX 切换到“下载”目录、写入唯一文件名并点击“保存”。程序只接受新增且连续两次扫描大小稳定的文件，随后关闭保存面板和预览窗口。如果下载仍未产生文件，则在关闭前截取当前图片预览窗口，使 Codex 仍能视觉分析客户图片。图片会验证 20 MB 上限、JPEG/PNG 有效性、像素尺寸和 SHA-256，原子落盘后按消息顺序作为 `codex exec --image <本地图片>` 参数传给 Codex。

当前版本不发送知识库图片，也不上传非客户原图附件。

## 客户视频

视频下载采用持久状态机。单次主线路使用有限连接/响应时间，失败后尝试保持原域名、TLS 与签名 URL 不变的备用解析线路；仍失败时按 60 秒、180 秒、600 秒在后台重新定位该客户并取得新地址。第一次失败会把固定提示“亲，视频暂时无法加载，麻烦您先简单描述一下需要我们查看的问题。”加入该客户队列且只加入一次；以后视频恢复成功仍会继续抽帧、提取音轨并进入原客户的 Codex 分析队列，不会撤销已经发送的提示。

持久状态只记录客户/消息哈希、阶段、重试次数、下次时间和本地文件名，不保存临时签名 URL。拼多多的红点、身份、媒体识别与打开视频算法保持不变。

## 数据隔离

现有自动客服仍使用 `~/Desktop/拼多多AX记录/自动回复/`。候选版使用：

```text
~/Library/Application Support/PDDAutoReplyTaskIsolationCandidate/拼多多AX记录-任务隔离候选版/
```

两版 Bundle ID、可执行文件、状态库和日志不同；共享运行锁会阻止它们同时控制拼多多。

## 权限

候选版使用新的 Bundle ID，首次运行必须在“系统设置 → 隐私与安全性 → 辅助功能”中单独允许“拼多多全自动客服-任务隔离候选版”。OCR 还需要屏幕录制权限。授权后重新打开候选版。
